# 0.10.5 plan: quality pass

No feature. 0.10.5 fixes the defects that a whole-repository review, a debug pass over the seams
between areas and exploratory runs of the staged module found; cuts the three test suites down to
tests worth their cost; corrects the documentation; and archives the finished 0.9.15 plan. It
follows 0.10.0 as 0.7.5 and 0.9.5 followed theirs. The developer runs the release from this plan:
the version bump, `CHANGELOG.md` and the release notes are not part of it.

The pass ran unattended overnight on 2026-10-05. Every choice that would have needed an answer is
in section 3, Decisions, so that it can be reversed.

## 1. Outcome

- Every confirmed defect is fixed with a regression test that failed before the fix, or recorded
  as not fixed or owed, with the reason.
- The Core, product Pester and tooling suites are shorter and faster: tests that cannot fail,
  restate the implementation, repeat another test through the same path, or assert what a golden
  already pins are removed or merged, each with evidence; slow tests are made at least twice as
  fast without weakening their assertions.
- Guides and help match the code in both cultures.
- `verify` exits 0 five times in a row with the same counts, and once with
  `ADOTOOLKIT_RELEASE_BUILD=1`, with every warnings array empty.

No public contract change is expected: no cmdlet, parameter, output type, configuration setting
or schema changes. A corrupt compressed body becomes a typed `Ado*` error instead of a raw
`InvalidDataException`; that is the fix, not a contract change.

## Critique

Critic: `gpt-6.1-sol` through the `critique` skill, effort max, repository mode, 2026-10-05, on the
draft of this plan (37,376 characters). Footer: `critique: model gpt-6.1-sol, effort max, mode
repo, 842.1 s, tokens in 1245584 (cached 1115648), out 20331 (reasoning 13520)`. Four findings,
each verified against the tree before triage: four applied, none rejected, none owed.

1. **Moving backup cleanup after commit still endangers other versions' recovery copies** (HIGH) —
   **applied**. Verified: the sweep in `tools/package/Install-AdoToolkit.ps1` matches
   `\d+\.\d+\.\d+\.previous-[0-9a-f]{32}` for every version, while an install commits one, so the
   draft's fix would still delete `0.1.0.previous-<guid>`, the only copy of 0.1.0, when 0.2.0
   installs. A backup is now removed only when its own version folder exists, after the commit;
   phase 3 tests a failed install and a successful install of another version beside an orphaned
   backup. Section 3 records the rule.
2. **Preserving object text does not justify interpreting remote terminal controls** (MEDIUM) —
   **applied**. Verified: `AGENTS.md` requires encoding external data for its destination, the work
   item view writes `Title` through `<PropertyName>`, and the exploratory run saw ESC stripped only
   because its output was redirected. New fix R-23 (phase 2); the "not a defect" row is gone.
3. **Budget 16 covers a failure boundary that the retained neighboring rows do not** (MEDIUM) —
   **applied**. The history server's build 397 holds two runs, and budget 16 is the row that stops
   after the first; it stays. Every other row removal still needs its own mutation proof.
4. **S8 risks losing the character-versus-byte limit check** (MEDIUM) — **applied**. The input
   accepted at exactly `SafeXml.MaximumCharacters` keeps an `é`, so its UTF-8 length is over the
   limit; one multibyte character is enough to tell a character count from a byte count.
